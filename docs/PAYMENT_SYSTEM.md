# Система оплаты и автоматического управления хостингом

## Обзор

Система автоматически управляет жизненным циклом хостинга:
1. **Предупреждение** — за 2 недели до истечения
2. **Отключение** — через 2 недели после истечения
3. **Удаление** — через 2 месяца после истечения

## Компоненты

### 1. Платежи (Payments API)

**Endpoints:**
- `POST /api/payments` — создать платеж
- `GET /api/payments/{id}` — получить информацию о платеже
- `GET /api/payments/{id}/qr` — получить QR код
- `POST /api/payments/{id}/verify` — проверить статус оплаты
- `GET /api/payments?site_id={id}` — список платежей по сайту

### 2. Автоматические задачи (Cron Jobs)

Запускаются каждый час:

- **Проверка предупреждений** — отправка уведомлений менеджерам за 2 недели до истечения
- **Автоотключение** — остановка сайтов через 2 недели после истечения
- **Автоудаление** — удаление сайтов через 2 месяца после истечения

## Процесс оплаты

### Для менеджера:

1. Менеджер открывает сайт → видит статус хостинга
2. Нажимает "Продлить хостинг" → попадает на страницу оплаты
3. Выбирает план и период → создается платеж
4. Получает QR код для оплаты
5. После оплаты нажимает "Проверить оплату"
6. (Админ подтверждает) → хостинг продлевается

### Для админа:

1. Видит список всех сайтов в `/admin/sites`
2. Может вручную:
   - Запустить/остановить/перезапустить сайт
   - Удалить сайт
   - Продлить хостинг
3. Может подтвердить платеж вручную через админ-панель

## QR Код

QR коды генерируются с помощью библиотеки `qrcode`. Данные для QR кода содержат информацию о платеже в формате JSON.

### Установка зависимостей

```bash
pip install qrcode[pil] pillow
```

### Формат данных QR кода

```json
{
  "type": "sbp_payment",
  "id": "payment_uuid",
  "amount": 500.00,
  "description": "Оплата хостинга: Company Name (basic, 1 мес.)",
  "timestamp": "2024-01-15T10:30:00Z"
}
```

### Варианты интеграции с реальной платёжной системой:

1. **ЮKassa** (рекомендуется для РФ)
   - API для создания платежей
   - Автоматические webhook для подтверждения
   - QR коды для оплаты

2. **CloudPayments**
   - Аналогично ЮKassa
   - Хорошая документация

3. **СБП (Система Быстрых Платежей)**
   - Через банковский API
   - QR коды формата НСПК

## Конфигурация

Cron jobs запускаются автоматически при старте API сервера. Проверяют каждые 60 минут.

### Уведомления

Уведомления отправляются через bot webhook:
```bash
BOT_WEBHOOK_URL=http://bot:8081
```

## Интеграция платежной системы

Для интеграции с реальной платежной системой нужно:

1. Обновить `routes/payments.py`:
   ```python
   async def generate_payment_qr(payment_id: str, amount: float, description: str):
       # Создать платеж в ЮKassa
       payment = await yookassa.create_payment({
           "amount": {"value": amount, "currency": "RUB"},
           "confirmation": {"type": "qr"},
           "description": description
       })

       return {
           "qr_code_url": payment.confirmation.qr_code,
           "payment_url": payment.confirmation.confirmation_url,
           "expires_at": payment.expires_at.isoformat(),
           "external_id": payment.id
       }
   ```

2. Добавить webhook для автоматического подтверждения:
   ```python
   @router.post("/webhook/yookassa")
   async def yookassa_webhook(data: dict):
       # Проверить подпись
       # Обновить статус платежа
       # Продлить хостинг
   ```

### Откат автоматического отключения

Если менеджер оплатил после отключения:
1. Админ подтверждает платеж
2. Хостинг продлевается
3. `auto_disabled_at` остается для истории
4. Сайт можно вручную запустить

## Безопасность

- Все платежи требуют авторизации
- Админ может подтверждать платежи вручную
- QR коды истекают через 24 часа
- Удаление сайтов необратимо (только админ)

## Мониторинг

### SQL запросы для мониторинга:

```sql
-- Сайты с истекающим хостингом
SELECT * FROM expiring_sites;

-- Статистика сайтов
SELECT * FROM sites_stats;

-- Неоплаченные платежи
SELECT * FROM hosting_transactions
WHERE status = 'pending'
  AND expires_at > NOW()
ORDER BY created_at DESC;
```
